Vá para **SQL Editor**\n\n### 2️⃣ Criar Tabela de Inspeções\n\nCopie e execute este SQL no **SQL Editor**:\n\n```sql\n-- Criar tabela de inspeções\nCREATE TABLE inspections (\n  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),\n  rope_type TEXT NOT NULL,\n  condition TEXT NOT NULL,\n  location TEXT NOT NULL,\n  notes TEXT,\n  images TEXT[] DEFAULT '{}',\n  date TIMESTAMP DEFAULT now(),\n  created_at TIMESTAMP DEFAULT now(),\n  updated_at TIMESTAMP DEFAULT now()\n);\n\n-- Criar índice para melhor performance\nCREATE INDEX idx_inspections_created_at ON inspections(created_at);\n\n-- Habilitar RLS (Row Level Security)\nALTER TABLE inspections ENABLE ROW LEVEL SECURITY;\n\n-- Criar política para permitir todos os acessos\nCREATE POLICY \"Enable all access\" ON inspections\n  FOR ALL USING (true)\n  WITH CHECK (true);\n\n-- Criar política para DELETE\nCREATE POLICY \"Enable delete access\" ON inspections\n  FOR DELETE USING (true);\n```\n\n### 3️⃣ Criar Bucket de Armazenamento\n\n1. No painel Supabase, clique em **Storage** (lado esquerdo)\n2. Clique em **Create a new bucket**\n3.
